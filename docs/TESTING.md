## 安装后需要操作者手动完成的检查

以下步骤需要真机、root 和人工听感判断，仓库里没有自动化测试覆盖。
请在执行前先记录原始 vendor 文件的哈希，便于回滚核对。

```bash
# 安装前（需要 root shell）
sha256sum /vendor/etc/audio_device.xml
# 期望：0d173c2bf7db1b8669926f23135596114f243458697c5dbfc2fa4572a88b56ba
```

1. 用 Magisk 安装 release ZIP（不是 GitHub 的 "Source code" 压缩包），重启。
2. 媒体播放（低音量，建议 3/15）：确认听筒与主扬声器同时出声。
3. 铃声：确认是否也走 `speaker_output`（预期会，但**未验证**）。
4. 免提通话：确认听筒是否同时出声；普通听筒通话是否正常。
5. 插入耳机：确认耳机输出正常、外放静音。
6. 蓝牙：确认蓝牙输出正常。
7. 最大音量：**不建议**在本实验版本上做长时间最大音量测试。
8. 禁用或删除模块并重启，确认 `/vendor` 恢复原样（哈希回到基线值）。
